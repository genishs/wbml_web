## 0. 한눈 요약 (TL;DR)

- 장르: **액션 RPG 플랫포머** (사이드뷰, 강제 진행 아님 / 라운드 단위 클리어형).
- 아케이드 원판은 **총 11 라운드(Round 1~11)**. SMS 이식판은 12 스테이지(아케이드 7↔8 라운드 사이에 한 스테이지를 추가). **우리는 11 라운드를 채택한다.**
- HP는 **하트(최대 시작 5개, 점수로 최대 10개까지 확장)**. 화면 상단 **모래시계 타이머가 다 떨어지면 하트가 1개 깎이고 타이머가 뒤집혀 다시 시작** — HP를 지속적으로 압박하는 핵심 메커니즘.
- **첫 검 Gradius(그라디우스)만 상점에서 획득**(원판 스토리상 마을에서 받는 첫 무기). 이후 Bronze→Great→Excalibur→Legend 검은 **보스 처치로만** 획득(가격 구매 불가). 방패/갑옷/신발/마법은 상점 구매.
- 골드는 적 처치·숨은 보물에서 획득. 병원/술집(여관)에서 회복하며, **병원 숙박비는 이용할 때마다 상승(20→40→70…)**.
- 최종 보스 = **MEKA Dragon(메카 드래곤)** — 평범한 드래곤으로 보이나 처치 후 외계 로봇으로 밝혀짐. 처치 시 엔딩(3편으로의 클리프행어).

## 1. 게임 개요 / 재현 목표 / 톤

### 1.1 개요
플레이어는 소년 영웅 **Tom-Tom(원더 보이)** 이 되어, 메카 드래곤이 점령한 몬스터 랜드를 가로지른다. 각 라운드를 좌→우로 진행하며 적을 쓰러뜨리고 골드를 모아 장비를 갖추고, 라운드 끝의 보스(가디언)를 처치해 **열쇠를 얻어 다음 라운드의 문을 연다**. 액션(점프·검 공격)과 경량 RPG(상점·장비 성장·골드 경제)가 결합된 구조다.

### 1.2 재현 목표
- **아케이드 원판의 라운드 구성·메커니즘·페이싱을 충실히 복원**하는 것이 1차 목표다. 임의 창작·추가 요소는 지양한다.
- 현재 working tree에 12라운드(SMS식)로 확장한 미완성 작업(`src/stage.js`, `src/enemy.js`)이 있으나, **아케이드 원판은 11라운드이므로 11라운드를 정본으로 삼는다.** (코드 수정은 본 임무 범위 밖 — 기획상의 권고로만 기재.)
- 픽셀 아트·HUD 레이아웃은 아케이드 화면 구성(좌측/하단 스테이터스 패널 + 우측 게임 뷰)을 참고하되, 웹 캔버스(640×360, 좌측 112px HUD)는 현 구현을 유지한다.

### 1.3 톤
밝고 동화적인 판타지. 컬러풀한 픽셀 아트, 경쾌한 BGM, 위트 있는 보스(예: 수수께끼를 내는 스핑크스). 난이도는 아케이드답게 **시간 압박 + 골드 관리 + 장비 게이팅**으로 빡빡하되, 죽음은 즉각적이고 명확하다.

## 2. 코어 루프 & 라운드 진행 구조

### 2.1 코어 루프
```
라운드 시작(좌측 진입)
  → 우측으로 전진하며 적 처치(골드·점수·가끔 하트 드롭)
  → 도중의 상점 문 입장(방패/갑옷/신발/마법 구매) · 병원/술집에서 회복
  → 숨은 문/벽 노크로 비밀 보너스(골드·편지·아이템) 탐색
  → 라운드 끝 보스(가디언) 처치 → 검 업그레이드(해당 라운드 한정) 또는 열쇠 획득
  → 열쇠로 게이트를 열어 다음 라운드로
  (그 사이 내내 모래시계 타이머가 HP를 압박)
```

### 2.2 라운드 구성표 (아케이드 11라운드)

> 출처 주의: StrategyWiki의 라운드 페이지 번호는 **SMS(12라운드) 기준**이라, 후반부는 "아케이드 Round N ≈ SMS Round N+1"로 매핑된다(아케이드는 SMS가 7~8 사이에 끼워 넣은 스테이지가 없음). 아래 표는 아케이드 번호로 통일했다. 테마 명칭 일부는 시각 자료 기반 **원판 추정치**.

| 아케이드 R | 테마/지형(추정 포함) | 보스(가디언) | 보상/특징 |
|---|---|---|---|
| 1 | 마을 입구 · 들판/다리 | **Death(사신, Death Master)** — 낫을 든 비행형 | 첫 검 업그레이드 계열 / 튜토리얼 난이도 |
| 2 | 동굴·버섯 숲 | **Mushroom King(머쉬룸 킹)** — 쉴 새 없이 바닥을 튀어 다님 | 비밀 문(편지 전달 퀘스트 시작점) |
| 3 | 평지·계단/플랫폼 | **Red Knight(붉은 기사)** — 이후 다수 등장하는 기사형의 첫 등장 | 검 공격 패턴 학습 구간 |
| 4 | 섬/해안(야자수) | **Kraken(크라켄)** — 머리 위를 떠다니며 독 구체를 뿌림 | 점프·공중 회피 요구 |
| 5 | 산악/숲 | **Kong(콩)** — 매우 어려움, **Great Sword(그레이트 소드) 가디언** | 검 업그레이드 보상 |
| 6 | 사막/유적 | **Sphinx(스핑크스)** — 자신에 대한 질문 3지선다, 오답 시 강제 전투 | 정답 분기 / 매우 어려움 |
| 7 | 화염/불의 영역 | **Poor God(빈곤신) + 비밀 Demon(데몬)** — 데몬은 회전하는 불 구체 원이 커졌다 작아짐. **Excalibur(엑스칼리버) 가디언** | 선택적 비밀 보스 → 검 업그레이드 |
| 8 | 음습한 지역 | **Ghost(고스트)** — "가장 파괴적인 가디언" | 고난이도 구간 |
| 9 | 미궁/요새 입구 | **Minotaur(미노타우로스)** — 검+도약, 멀어지면 무지개 레이저 발사 | 기사 상위 변형 |
| 10 | 물가/늪 | **Great Catfish(거대 메기)** — 격파 시 Hero Emblem(영웅 문장) 부여, 종/루비 분기 선택 | 루비=최종보스 HP 절반 / 종=미궁 길안내 |
| 11 | **Castle of No End(끝없는 성)** — 미로형 최종 성 | **보스 러시 → 최종보스 MEKA Dragon(메카 드래곤)** | 이전 가디언 다수 재등장(물량전), 마지막에 메카 드래곤 |

**메카 드래곤(최종):** 히트박스가 가슴 주변 작은 영역에만 존재해 매우 까다로움. 화염 발사 전 3가지 이동 패턴(돌진 / 작은 도약 / 큰 도약)을 가짐. 처치 시 외계 로봇 정체가 드러나며 엔딩.

### 2.3 클리어 조건
- 각 라운드: 보스 격파 → (필요 라운드) 열쇠 획득 → 게이트 통과.
- 게임 클리어: Round 11에서 **메카 드래곤 격파** → 엔딩 데모(차기작 클리프행어).

## 3. 시스템 정의

### 3.1 하트 / HP
- 시작 하트 **5개**(원판). 점수 마일스톤마다 **최대 하트 1칸 확장, 최대 10칸**.
  - 점수 임계값: 자료에 따라 (a) 30,000 후 50,000 간격, (b) SMS는 100k/200k/300k/400k. **아케이드 정확 임계값은 원판 추정치** → 기본안: **30,000 / 80,000 / 130,000 / 180,000 …(또는 100k 간격)**, 열린 질문 참조.
- 피격 시 하트 일부/전부가 검게 변함. **모든 하트가 검어지면 사망.**
- 회복 수단: 적이 드롭하는 **작은 하트(소량 회복)** / **큰 하트(완전 회복)**, 병원 숙박, 술집(여관) 음료, 모래시계 아이템(시간 회복).

### 3.2 타이머 (HP 드레인 핵심)
- 화면 상단 **모래시계**가 위→아래로 모래를 계속 흘려보낸다.
- **모래가 다 떨어지면 하트 1칸이 깎이고**, 모래시계가 뒤집혀 처음부터 다시 흐른다. (즉시 게임오버가 아니라, **HP를 지속적으로 깎는 압박**.)
- 모래시계 아이템을 먹으면 시간(모래)이 보충된다. 병원/술집도 시간을 회복.
- ※ 현 웹 구현(`constants.js: HP_DRAIN_RATE`, README "시간 초과 시 즉사")은 **즉사 모델**이라 아케이드와 다름 → 아케이드식 "타이머 0 = 하트 1 감소 후 리셋"으로 변경 권고(열린 질문).

### 3.3 골드 경제
- 획득: 적 처치, 바닥/벽 속 **숨은 골드(주머니/보물)**, 일부 보스 보상.
- 사용처: 방패·갑옷·신발·마법 상점, 병원(회복), 술집(회복), 일부 비밀 거래.
- **병원 숙박비 누진:** 1회 20G → 2회 40G → 3회 70G … (이용할수록 비싸짐). 골드 관리가 곧 난이도.

### 3.4 장비 시스템 (아케이드 정본)

**중요한 아케이드 사실 두 가지:**
1. **검(sword) 획득 = 첫 검 Gradius만 상점, 이후는 보스 드롭.** 첫 검 Gradius(그라디우스)는 마을 상점에서 얻고(원판 스토리), 그 다음 Bronze→Great→Excalibur→Legend 업그레이드는 **특정 보스를 격파해야만** 얻는다(가격 구매 불가).
2. 방패·갑옷·신발·마법은 **상점 구매**.

#### 3.4.1 검 (Gradius=상점 획득, 이후=보스 드롭)
| 단계 | 검(명칭, 통용 표기) | 획득처(아케이드) | 비고 |
|---|---|---|---|
| 0 | 기본 검(Short/Dagger) | 시작 장비 | |
| 1 | **Gradius(그라디우스)** | **상점에서 획득**(스토리상 첫 무기) | 유일하게 상점 획득 검 |
| 2 | **Bronze Sword(브론즈 소드)** | 보스 격파(초반) | 보스명 일부 원판 추정치 |
| 3 | **Great Sword(그레이트 소드)** | **Round 5 Kong** 격파 | |
| 4 | **Excalibur(엑스칼리버)** | **Round 7 Poor God/Demon(비밀 보스)** 격파 | 선택적 비밀 전투 |
| 5 | **Legend Sword(레전드 소드)** | 후반 보스 격파 | 최종 검 |

### 3.5 적 / 보스 스탯 (원판 추정치 — 상대값)
> 아케이드 원전은 적별 정확 HP/ATK 수치를 공개 자료로 확정하기 어렵다. 아래는 **밸런스 가이드용 상대 추정치**이며, QA는 "절대값 일치"가 아니라 "상대 난이도·행동 패턴 일치"로 검증한다.

| 적 | 행동 특징 | 상대 HP | 상대 ATK | 비고 |
|---|---|---|---|---|
| 잡몹(슬라임/오크류) | 지상 순찰 | 낮음 | 낮음 | 골드 소량 |
| 박쥐/비행체 | 비행, 사인 곡선 | 낮음 | 낮음 | |
| 화염/투사체 | 직선 고속 | 1 | 중 | 방패로 차단 가능 |
| 기사(Knight) | 검·도약 | 중 | 중 | Red→Blue 상위 변형 |
| 후반 정예 | 마법·레이저 | 높음 | 높음 | |

**보스 행동 패턴(정성, 복원 우선순위 ★):**
- ★ Death: 비행 + 낫 휘두름, 좌우 이동.
- ★ Mushroom King: 끊임없이 바닥 바운스(점프 타이밍 싸움).
- Kraken: 머리 위 부유 + 독 구체 낙하.
- Sphinx: 3지선다 질문 → 오답 시 전투.
- Demon(R7 비밀): 회전 불 구체 원이 주기적으로 확대/축소.
- Minotaur: 검·도약 + 원거리 무지개 레이저.
- ★ Meka Dragon: 가슴만 약점(작은 히트박스), 화염 전 돌진/소도약/대도약 3패턴.

## 4. 라운드별 사양 (복원 스펙)

> 좌표·문 위치는 아케이드 정확값이 자료로 없으므로 **상대 배치 원칙**으로 규정한다(QA는 배치 원칙 준수로 검증). 길이·플랫폼 수는 현 `stage.js` 스케일을 재활용하되 **11라운드로 축소**한다.

각 라운드 공통 사양:
- **진행 방향:** 좌→우. 시작점은 좌측 끝, 목표(보스 방/게이트)는 우측 끝.
- **상점 문:** 라운드당 0~여러 개. 초반(R1~2)은 상점 밀집, 후반은 희소. **R11(최종)은 상점 없음/최소.**
- **회복 시설:** 병원 또는 술집(여관) 최소 1곳 권장(후반은 희소).
- **비밀 요소:** 벽 노크/위쪽 입력으로 진입하는 **숨은 문**(골드·편지·아이템). 숨은 곳 근처 통과 시 1초간 "?" 표시.
- **보스 방:** 우측 끝 전용 문 안. 격파 시 검 업그레이드(해당 라운드) 또는 열쇠/게이트 개방.

라운드별 핵심(테마/보스/특이점)은 **2.2 표** 참조. 복원 시 아래 우선순위로 채운다:
1. 보스 행동 패턴(★ 항목 우선)
2. 테마 비주얼(배경/지형)
3. 적 조합(라운드 진행에 따라 점증)
4. 상점/회복/비밀 배치(상대 원칙)

## 5. 수용 기준 (Acceptance Criteria — QA 검증용)

### 5.1 구조 (아케이드 일치)
- [ ] **AC-S1** 총 라운드 수가 **정확히 11**이다(SMS의 12가 아님).
- [ ] **AC-S2** 라운드 순서·보스 매핑이 2.2 표와 일치(특히 R1=Death, R11 최종=Meka Dragon).
- [ ] **AC-S3** R11은 보스 러시 성격(이전 가디언 재등장 물량전) + 최종 메카 드래곤으로 끝난다.

### 5.2 HP / 타이머
- [ ] **AC-H1** 시작 하트 5, 점수로 최대 10까지 확장된다.
- [ ] **AC-H2** 모든 하트가 소진되면 사망(게임오버 흐름 진입).
- [ ] **AC-T1** 모래시계가 0이 되면 **즉사하지 않고 하트 1칸만 깎인 뒤 타이머가 리셋**된다. (현 즉사 모델과 다름 → 변경 검증.)
- [ ] **AC-T2** 모래시계 아이템/병원/술집이 타이머(시간)를 회복시킨다.

### 5.3 장비 / 경제
- [ ] **AC-EQ1** **첫 검 Gradius는 상점에서 획득**되고, 그 이후 검(Bronze/Great/Excalibur/Legend)은 **상점 구매 불가 · 지정 보스 격파로만** 업그레이드된다.
- [ ] **AC-EQ2** 방패/갑옷/신발/마법은 상점에서 구매 가능하고, 등급 순서대로 게이팅된다.
- [ ] **AC-EQ3** 방패 가격이 **40 / 120 / 250 / 360G**(라이트/나이트/하드/레전더리)와 일치.
- [ ] **AC-E1** 병원 숙박비가 누진한다(20→40→70… 순서).
- [ ] **AC-E2** 적 처치·숨은 보물에서 골드를 얻는다.

### 5.4 전투 / 보스
- [ ] **AC-B1** Meka Dragon은 약점 히트박스가 작고(가슴 부근), 화염 전 3패턴(돌진/소도약/대도약)을 보인다.
- [ ] **AC-B2** Mushroom King은 지속 바운스, Sphinx는 3지선다 질문 등 ★보스 패턴이 재현된다.
- [ ] **AC-C1** 방패가 원거리 투사체(화염/화살) 일부를 차단한다.

### 5.5 진행 / 엔딩
- [ ] **AC-P1** 보스 격파로 열쇠/게이트가 열려 다음 라운드로 진행된다.
- [ ] **AC-P2** R11 메카 드래곤 격파 시 엔딩(클리프행어)으로 마무리된다.

## 7. 아케이드 ↔ 이식판 차이로 주의한 점 (복원 시 함정)

1. **라운드 수: 아케이드 11 vs SMS 12.** SMS는 아케이드 7~8 사이에 한 스테이지를 추가. → **11 채택.** (working tree의 12라운드 작업은 SMS식이므로 11로 축소 권고.)
2. **StrategyWiki 라운드 번호는 SMS 기준.** 후반부는 "아케이드 R = SMS R+1"로 매핑해 읽어야 함(예: SMS Round 9 Minotaur = 아케이드 Round 9 위치지만 페이지 번호 어긋남에 주의).
3. **검 획득 방식: 아케이드는 보스 드롭(구매 불가).** 현 `equipment.js`/README의 "검 상점 판매(50G~8000G)"는 SMS/리메이크식 → 아케이드 복원 시 보스 드롭으로 전환.
4. **타이머: 아케이드는 "0이면 하트 -1 후 리셋".** 현 구현/README의 "시간초과 즉사"와 다름.
5. **스테이터스 표시:** 아케이드는 화면 가장자리 스테이터스 패널, SMS는 일시정지 메뉴. 우리는 좌측 HUD 패널(아케이드 쪽 정신)을 유지.
6. **최대 하트 확장 점수 임계값은 아케이드/SMS가 다를 수 있음**(아케이드 정확값 미확정).
